# Time Series World Models: Benchmark and Directional Supervision

Code for the paper *On the Divergence of Accuracy and Mechanism Consistency in Time
Series World Models*. It contains the data loaders, the training and evaluation code, the
mechanism-consistency probe, the directional-supervision objective, and the launch
scripts of every experiment in the paper. Result files are not included; every number is
regenerated by the commands below.

## Layout

```
dataset_utils/            loaders of the eight datasets, splits and windowing;
                          mimic_cardio/build.py extracts MIMIC-Cardio from MIMIC-IV
rq2_latent_vs_ob/         Experiment 1 (prediction space): observation space vs AE / VAE / JEPA
  common/                 shared data layer and the seven backbones (common/ts_benchmark, TFB code)
  observational_space/    training and evaluation in observation space
  latent_space/           codec pretraining, JEPA, training and evaluation in latent space
  scripts/                manifest generator and array launchers of the five-seed sweep
RQ3_fusion_benchmark/     Experiment 2 (plan fusion): none / concat / res / res_zero / film_zero / xattn / gate
RQ4_action_encoding/      Experiment 3 (plan encoding): instant / decay / conv / attn
RQ5_autonomy_split/       Experiment 4 (auxiliary loss on the pre-fusion latent)
RQ6_intervention/         declared mechanisms (priors.py) and the mechanism-consistency probe
RQ7_causal_fusion/        directional supervision (gate_soft) on top of the gate arm
```

Every experiment writes one JSON per (dataset, backbone, seed) cell under
`<experiment>/results/`, and every training run stores its best-validation checkpoint
under `<experiment>/results/.../ckpts/`.

## Environment

Python 3.10 or later with CUDA-enabled PyTorch. Install the packages in
`requirements.txt`:

```
pip install -r requirements.txt
```

`vitaldb` is needed only to download VitalDB, `pyarrow` only for MIMIC-Cardio, and
`wandb` only if logging is turned on (`WANDB=1`, the default of the Experiment 1
launchers; set `WANDB=0` to disable it).

## Data

Set `DATA_ROOT` to a directory with the following layout. The eight datasets are public;
the seven non-MIMIC ones are downloaded from their original sources (cited in the paper),
and MIMIC-Cardio is built locally from MIMIC-IV v3.1, which requires PhysioNet
credentialed access and cannot be redistributed.

```
$DATA_ROOT/
  greenhouse3/TimeSeries/<team>/GreenhouseClimate.xlsx, Weather.xlsx     (Greenhouse, 4TU 10.4121/21960932)
  PLEIAData/processed_data/data-room{A,B,C}-10T.csv                       (PleiaData)
  PreDist/predist_dataset/manufacturer_2/operational_data/substation_*.csv (PREDIST)
  Wastewater_Treatment_Plant_Data_for_Nutrient_Removal_System/IOPTQCfFiFoNPo_2min_Agtrup_Aug_2023.csv
  vital_db/                      (VitalDB; filled by the loader through the vitaldb package with --download)
  diabetes_datasets/cgmacros/CGMacros/CGMacros-0XX/CGMacros-0XX.csv, bio.csv   (CGMacros)
  diabetes_datasets/Shanghai_T1DM_T2DM/Shanghai_T1DM/, Shanghai_T2DM/          (Shanghai)
  mimic_cardio/grid_30min/grid.parquet, cohort.parquet                          (built below)
```

MIMIC-Cardio:

```
python -m dataset_utils.mimic_cardio.build --mimic-root <MIMIC-IV v3.1 csv root> \
    --out-root $DATA_ROOT/mimic_cardio --grid-min 30
```

## Reproducing the experiments

All launchers are Slurm array jobs that read one line of a manifest per task. Set
`REPO_DIR`, `DATA_ROOT`, `CONDA_ENV` (and `CONDA_SH` if conda is not under
`$HOME/miniconda3`), create `logs/` in the repository root, and submit from the
repository root. The forecasting protocol (context 256, horizon 16, stride 80, 100 epochs,
patience 20, batch 128, learning rate 1e-3, MSE loss, gradient clipping 1.0, validation
ratio 0.2, data seed 0, training seeds 0 to 4) is fixed inside the launchers.

Step 0. Window cache and the frozen AE codec of each dataset, then the VAE codec (the
JEPA arm trains its encoder jointly and needs no codec):

```
sbatch --export=ALL --array=0-6 rq2_latent_vs_ob/scripts/seeds_stage0.slurm
DATASET_SWEEP="mimic_cardio" sbatch --export=ALL --array=0 rq2_latent_vs_ob/scripts/seeds_stage0.slurm
for d in greenhouse vitaldb cgmacros shanghai_diabetes pleiadata predist wastewater_nutrient mimic_cardio; do
  PREPARE_ONLY=1 CODEC=vae DATASET=$d DEVICE=cuda OUT_ROOT=results/latent_space/target \
    bash rq2_latent_vs_ob/latent_space/scripts/latent_train_eval.sh
done
```

Step 1. Experiment 1, prediction space (obs / ae / vae / jepa, 7 backbones, 8 datasets,
5 seeds):

```
python rq2_latent_vs_ob/scripts/gen_seed_manifest.py --out rq2_latent_vs_ob/scripts/seed_manifest.txt
MANIFEST=rq2_latent_vs_ob/scripts/seed_manifest.txt sbatch --export=ALL --array=0-<N-1> rq2_latent_vs_ob/scripts/seeds_stage1.slurm
```

The generator prints the exact `--array` range; the same holds for every generator below.

Step 2. Experiment 2, plan fusion (the `concat` arm is the `ae` arm of Experiment 1):

```
python RQ3_fusion_benchmark/scripts/gen_fusion_manifest.py --out RQ3_fusion_benchmark/scripts/fusion_manifest.txt
MANIFEST=RQ3_fusion_benchmark/scripts/fusion_manifest.txt sbatch --export=ALL --array=0-<N-1> RQ3_fusion_benchmark/scripts/fusion_cells.slurm
```

Step 3. Experiment 3, plan encoding (the `instant` arm is the corresponding fusion arm of
Experiment 2):

```
python RQ4_action_encoding/scripts/gen_encoding_manifest.py --out RQ4_action_encoding/scripts/enc_manifest.txt
MANIFEST=RQ4_action_encoding/scripts/enc_manifest.txt sbatch --export=ALL --array=0-<N-1> RQ4_action_encoding/scripts/encoding_cells.slurm
```

Step 4. Experiment 4, auxiliary loss (lambda = 0 is the `gate` arm of Experiment 2):

```
python RQ5_autonomy_split/scripts/gen_autonomy_manifest.py --out RQ5_autonomy_split/scripts/auto_manifest.txt
MANIFEST=RQ5_autonomy_split/scripts/auto_manifest.txt sbatch --export=ALL --array=0-<N-1> RQ5_autonomy_split/scripts/autonomy_cells.slurm
```

Step 5. Mechanism consistency of the trained models (no training). Build the held-out
window banks and the action ranges once, then run the probe over the manifests: the
fusion arms on all datasets, the prediction-space and plan-encoding arms on the four
engineered datasets, and the same on the two clinical datasets.

```
python RQ6_intervention/scripts/build_probe_cache.py
python RQ6_intervention/scripts/extract_action_ranges.py
python RQ6_intervention/scripts/gen_probe_manifest.py --out RQ6_intervention/scripts/probe_manifest.txt
python RQ6_intervention/scripts/gen_probe_manifest.py --sec4 --out RQ6_intervention/scripts/probe_manifest_sec4.txt
for m in probe_manifest probe_manifest_sec4 probe_manifest_sec4_clinical; do
  MANIFEST=RQ6_intervention/scripts/$m.txt sbatch --export=ALL --array=0-$(($(wc -l < RQ6_intervention/scripts/$m.txt)-1)) RQ6_intervention/scripts/probe_cells.slurm
done
```

Step 6. Directional supervision (`gate_soft`, rho = 0.1) on the four engineered datasets
with the default split of the declared mechanisms, and on the two clinical datasets with
the clinical split; then probe the trained models.

```
MANIFEST=RQ7_causal_fusion/scripts/soft_manifest.txt sbatch --export=ALL --array=0-139 RQ7_causal_fusion/scripts/soft_cells.slurm
PRIOR_SPLIT=clinical MANIFEST=RQ7_causal_fusion/scripts/soft_manifest_clinical.txt sbatch --export=ALL --array=0-69 RQ7_causal_fusion/scripts/soft_cells.slurm
MANIFEST=RQ6_intervention/scripts/probe_manifest_soft.txt sbatch --export=ALL --array=0-3 RQ6_intervention/scripts/probe_cells.slurm
MANIFEST=RQ6_intervention/scripts/probe_manifest_clinical.txt sbatch --export=ALL --array=0-3 RQ6_intervention/scripts/probe_cells.slurm
```

## Running a single cell without Slurm

Each launcher wraps one Python entry point that can be called directly, for example:

```
cd rq2_latent_vs_ob
DATASET=predist DEVICE=cuda MODELS="TiDE" WANDB=0 bash observational_space/scripts/ac_train_eval.sh
DATASET=predist DEVICE=cuda MODELS="TiDE" CODEC=ae WANDB=0 bash latent_space/scripts/latent_train_eval.sh
cd ../RQ3_fusion_benchmark
python fusion_train.py --datasets predist --models TiDE --arms gate --codec ae \
    --ae-dir ../rq2_latent_vs_ob/results/latent_space/target/ae --data-root $DATA_ROOT --device cuda \
    --context-length 256 --horizon 16 --stride 80 --epochs 100 --patience 20 --batch-size 128 \
    --lr 1e-3 --lr-patience 5 --loss mse --grad-clip 1.0 --val-ratio 0.2 --seed 0 --data-seed 0 \
    --ckpt-dir results/ae/ckpts --out results/ae/cells/predist__TiDE__gate__ae.json
```

`RQ4_action_encoding/encode_train.py`, `RQ5_autonomy_split/autonomy_train.py`,
`RQ7_causal_fusion/soft_cli.py` and `RQ6_intervention/scripts/probe_intervention.py` take
the same arguments as the launchers pass them.
